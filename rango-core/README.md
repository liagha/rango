# rango-core

Core of the [rango](https://github.com/liagha/rango) web framework: models,
routing, views, forms, and the request pipeline built on axum.

See the [workspace README](https://github.com/liagha/rango) for the full
guide, or [docs.rs/rango-core](https://docs.rs/rango-core) for the API
reference.
