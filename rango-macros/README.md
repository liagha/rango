# rango-macro

Procedural macros for [rango](https://github.com/liagha/rango): the `Model`
derive and the `#[rango::template]` / `#[rango::main]` attribute macros.

See the [workspace README](https://github.com/liagha/rango) for the full
guide, or [docs.rs/rango-macro](https://docs.rs/rango-macro) for the API
reference.
